Fórmula que usa esta calculadora

suma_asegurada = monto_base × % afianzado
factor_plazo = SI(plazo > 365 ; plazo / 365 ; 1)
Dentro de un año el precio no cambia (factor = 1). Solo aumenta cuando el plazo excede 365 días.
prima = suma_asegurada × tarifa × factor_plazo
DUV = prima × 0.035
total_sin_IVA = prima + DUV + gastos
IVA = total_sin_IVA × 0.16
total_con_IVA = total_sin_IVA + IVA
